# foxtrot

**Product manager and full stack engineer, at the same time.**

I write the roadmap and then I write the code: frontend, backend, mobile, LLM integration, and the database and deploy pipeline around them. Five years of it in global enterprise teams and on my own products.

## Open source

- **[GoalT](https://github.com/GOAL-T/goaltree)**: a goal graph engine that ranks work by how many goals it serves. On PyPI (`pip install goaltree`), in the official MCP registry, and shipped as a Claude Code plugin with a live dashboard.
- **[humancollab protocol](https://github.com/furkanYanteri1/humancollab-protocol)**: an open protocol for accountable statements between AI agents, businesses and people. Ed25519 signatures, a public Merkle log, MCP and A2A.

## What I build

- **Mobile apps on both stores:** React Native and Expo, offline first with SQLite sync to Supabase, subscriptions and ads, 673 unit tests behind one of them.
- **Platform apps:** a Canva marketplace app with a server side FFmpeg pipeline in Docker.
- **Production web platforms:** booking and operations systems, and a dealer catalog with a 3D viewer, built on React, Next.js and TypeScript.
